
# Currency Converter Project

## 1. Introduction
The Currency Converter is a Python-based project that converts one currency into another using fixed exchange rates.

## 2. Features
- Converts INR, USD, EUR and GBP.
- Supports multiple currency conversions.
- Checks invalid currency codes.
- Validates user input.
- Prevents negative amounts.
- Allows repeated conversions.

## 3. Technologies Used
- Programming Language: Python
- Concepts: Functions, Dictionary, If-Else, Loops, Try-Except

## 4. Supported Currencies

| Currency | Exchange Rate |
|----------|---------------|
| INR      | 1.0           |
| USD      | 83.0          |
| EUR      | 90.0          |
| GBP      | 105.0         |

## 5. How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

```bash
python currency_converter.py
```

5. Enter the amount.
6. Enter the source currency.
7. Enter the target currency.
8. See the converted amount.

## 6. Example Output

```text
CURRENCY CONVERTER

Enter amount: 100
From currency: USD
To currency: INR

Result: 100 USD = 8300.00 INR
```

## 7. Conversion Formula

Result = (Amount × Source Rate) / Target Rate

## 8. Conclusion

This project helps beginners understand Python programming concepts such as functions, dictionaries, loops, conditional statements and exception handling.

## 9. Note

Exchange rates are fixed sample values and are not live market rates.
